# Tasky

Organizador personal desarrollado con Flutter. Permite administrar tareas, categorías y eventos, con almacenamiento local en SQLite mediante Drift.

## Requisitos

- Flutter 3.41.4
- Dart 3.11.1 o superior, dentro del rango compatible con el proyecto

## Ejecutar

```bash
flutter pub get
flutter run
```

## Comprobar

```bash
flutter analyze --fatal-infos
flutter test
```
